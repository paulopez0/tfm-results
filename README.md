# Experimental results – TASA-Clang for OpenMP, CUDA and OpenCL

Raw measurements, scripts and figures of the master thesis
"Extension of TASA-Clang to parallel and heterogeneous programming models".

The results are distributed as a release asset (`tasa-results.tar.gz`).

Directory structure:

    <platform>/<input_size>/<power_mode>/<benchmark>/<model>/

- platform: xavier, orin, amd
- model: cpu (single-threaded), omp, cuda, opencl
